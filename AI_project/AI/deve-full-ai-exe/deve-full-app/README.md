## BUILD YOUR EXE (3 steps)

**Step 1** — Double-click `BUILD.bat`

That's it. It will:
1. Install Electron and build tools (~120 MB, first time only)
2. Package D.E.V.E into a Windows installer
3. Output two files in the `dist\` folder

**Your files:**
```
dist\DEVE-Setup-1.0.0.exe    ← Installer (recommended)
dist\DEVE-Portable-1.0.0.exe ← Portable (no install needed)
```

## TROUBLESHOOTING

**BUILD.bat fails with "node not found"**
→ Open BUILD.bat in Notepad, check the `NODE_DIR` path matches your Node.js location

**Voice not working**
→ Voice requires Chrome's speech engine. In the Electron app this is built in.
→ Check microphone permissions in Windows Settings → Privacy → Microphone

**App won't start after install**
→ Right-click the shortcut → "Run as Administrator" once
→ Windows Defender may flag new EXEs — click "More info" → "Run anyway"

**Slow on first launch**
→ Normal — Electron initializes on first run. Subsequent launches are instant.
