# D.E.V.E Renderer

A modern React + Tailwind + Framer Motion workspace for the futuristic AI interface.

## Setup

1. Open a terminal in `renderer`.
2. Run `npm install`.
3. Run `npm run dev`.

## Notes

- This workspace is designed as the new UI renderer for the D.E.V.E experience.
- The app uses Vite, React, Tailwind CSS, and Framer Motion.
